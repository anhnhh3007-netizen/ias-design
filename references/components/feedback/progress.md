# Progress
- Track height 4–8px, fully rounded, `--color-bg-hover`-family neutral track under a colored fill. Pair with a right-aligned `%` label whenever `showLabel` is on — don't float the label anywhere else.
- Fill color follows meaning, not decoration: brand for a neutral/default progress, success-green only when the tracked thing is a positive completion metric, warning when it's a "getting close to a limit" signal.

# Spinner
- Fixed size scale: 16 / 24 / 32 / 40px, 2–4px ring thickness scaling with size, `border-top-color` carrying the semantic color (brand by default).
- A standalone spinner (not embedded in a disabled `Button`) must always be paired with a short text label ("Đang tải...", "Đang tải dữ liệu...") — a bare spinning ring with no caption is not an accepted state.

# Icon
- Material Symbols Outlined ligatures only (`components/icons/`), never emoji in shipped UI (cross-cutting rule).
- Match optical size to context: 22–24px for standalone sidebar/nav icons, 18–20px for icons paired with header/toolbar buttons or inline with 13px body text, 16px or smaller only for compact inline hints (search icon inside a 36px field, small status glyphs).

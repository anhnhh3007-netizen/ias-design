# Toggle
- Track 36×20px, thumb 16px white circle with a soft shadow, `left: 2px` off / `left: 18px` on — never a differently-sized custom switch.
- Off track = `--color-border-default` (neutral gray). On track defaults to `--color-bg-brand`; only use the success-green track (`--color-bg-success-solid`) when the toggle's semantic is literally "activate/enable" (e.g. activate an account) rather than a generic setting switch — don't pick the green track for taste.

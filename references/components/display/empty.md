# Empty
- Icon in a 56px rounded-14 muted-gray square, bold 14px title, ≤2-line 12px muted description capped near 200px width, and **at most one** primary-variant action button below. Never pair it with a secondary button too — Empty states offer one obvious next step, not a choice.
- Use the "no data yet" variant (with action button) when a list/table is empty by default; use the "no results" variant (no action button, just re-search/filter guidance) when it's empty because of an active filter/search.

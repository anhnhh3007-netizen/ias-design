# Drawer
Right-side sliding panel for viewing one record's full detail without leaving the list screen — source at `components/overlay/Drawer/`.
- Anchored to the right edge, full height, slides in via `translateX` (never a centered/scale-in entrance like `Modal`) — same dim backdrop treatment as `Modal`, just repositioned.
- **Click-outside-to-close**: clicking the dimmed backdrop closes the drawer; clicking anywhere inside the panel does not. Implemented as a single `e.target === e.currentTarget` check on the backdrop's own click handler (see `Drawer.jsx`) — not `stopPropagation` on the panel — so the same technique works identically whether the drawer is a React component or hand-authored `.dc.html` markup (`DanhSachChuongTrinh.dc.html`'s `closeDrawerBackdrop` mirrors this exactly).
- **Width: `50vw`** (half the viewport) by default — updated 2026-07-31, was a fixed 720px. Floored at `480px` (`min-width`) so it doesn't get too cramped on narrow viewports, capped at `95vw` same as `Modal`. Override via the `width` prop for a screen that genuinely needs a different proportion; don't hardcode a pixel width as the default going forward.
- Header: title left (bold 16px, conventionally `"{Mã} - {Tên}"`, e.g. `"CT_123 - Kiểm toán hoạt động CNTT"`) + **two** icon buttons right — `open_in_full` (expand) then a close `✕`, in that order. This differs from `Modal`, which has a single bare close affordance.
  - `open_in_full`'s `onExpand` navigates to a full-page detail screen for that record — use `templates/ias-xem-chi-tiet/XemChiTiet.dc.html` as the base for that page (added 2026-07-31; back-arrow + title + status `Badge` + `Ý kiến`/`Lịch sử`/`more_vert` header, section-switcher, collapsible `Thông tin chung` + grouped-header detail table cards, centered "Đóng" footer). Wire it as an actual page navigation (`window.location.href` to the sibling template file), not a same-page state swap — the Drawer and the detail page are two separate `.dc.html` files, same as any other cross-template link in this project.
- Body: a 2-column grid of `Field` (see `references/components/display/field.md`) for read-only record fields — wraps to additional rows of 2, partial last row stays left-aligned. Not a fixed/closed field set like `FilterCard`'s grid — field count and labels follow whatever columns the source `Table` row has. Updated 2026-07-31: previously an ad-hoc 13px-bold-value style unique to `Drawer`; now uses `Field`'s canonical spec (12px/500 label, 14px/400 value, bottom divider) so `Drawer` and "Xem chi tiết" detail pages render fields identically.
- Footer: same order rule as `Modal`/`Card` (secondary left, primary right) — often just a single `outline` "Đóng" when the drawer is read-only with no save action.
- **Row trigger**: opened from a `Table` row via a `keyboard_double_arrow_right` icon button placed **near the front of the row, immediately after the primary mã/identity column** (not a trailing last column — see the placement rule and auto-placement heuristic in `references/components/data/table.md`) — this is a third accepted row-action pattern alongside text-link and `more_vert` overflow, used when the row's primary action is "view full detail inline" rather than navigate away or open a menu. Still mutually exclusive with the other two per row — pick one.

# DrSectionTitle

Section heading used inside `Drawer`'s body once it has 2+ sections — source at `components/overlay/DrSectionTitle/`. Formalizes what `references/components/overlay/drawer.md`'s "Multi-section title rule" previously described as a plain `11px/600 --color-text-secondary` caption; this is its real visual spec, replacing that draft treatment.

- **Title text**: `Subtitle 1` scale (`16px/600`, `--color-text-primary`) — matched per `typography-rules.md`'s size-first rule. Bolder and larger than the earlier caption-style draft; this is meant to read as a real section heading, not a muted label.
- **Accent bar, always present**: a short brand-colored bar directly under the title — `32px × 3px`, `2px` border-radius, `var(--color-bg-brand)`. Bespoke (no DS component covers "title + accent bar"), built with tokens per Step 2's "no equivalent → tokens only" rule. This bar is what identifies the element as a `DrSectionTitle` rather than a generic heading — never drop it.
- **Badge is optional, never required.** Pass one only when the section shows a variable-length related list worth a count (e.g. "3 đơn vị", "8 mã") — a section that's just a fixed field grid usually doesn't need one. When present, it sits inline with the title text (same row, `8px` gap), above the accent bar — not stacked on its own line, not below the bar.
  - **No dot.** `Badge`'s `dot` prop must stay `false`/omitted here — that's already `Badge`'s own default, so this isn't a new variant, just don't opt into `dot` in this context. A `DrSectionTitle` badge is a count/label chip, not a status indicator; per `references/components/display/badge-tag.md`, a non-status badge (e.g. a closable filter chip) already renders dot-less — this is the same case.
  - **Size `large`** (`Badge`'s own default, no need to pass `size` explicitly) — this title-row placement, alongside `Subtitle 1`-scale text, is one of the two contexts `large` is sized for; see `references/components/display/badge-tag.md`'s "Size by placement" section. Same rule applies to the plain (non-`DrSectionTitle`) `.d-card-header` count badge used in the Mapping NVTT full-page "Xem chi tiết" cross-reference cards (`mapCrossRefTitleHTML` in `can-cu-xu-phat-ias-redesign.html`) — same title-row placement, same size.
- **Containment**: one `DrSectionTitle` per `.dr-section`, directly above that section's content (a `Field` grid or a `Table`) — same placement rule as before, only the visual treatment changed.
- Reference implementation: `components/overlay/DrSectionTitle/dr-section-title.card.html`, and `Drawer`'s own `drawer.card.html` / Mapping NVTT's `Drawer` in `can-cu-xu-phat-ias-redesign.html` (`mapOpenDrawer`).

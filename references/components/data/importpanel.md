# ImportPanel (added 2026-08-14)
Dismissible **inline** 2-step import panel — download a template, then upload the filled-in file. Source at `components/data/ImportPanel/`.
- **Not a `Modal`.** No backdrop, no centered overlay, no dimming of the rest of the screen. It renders as its own card, inline inside `.list-panel`'s flow: directly below whichever of `ToolbarSimple`/`FilterCard` is currently visible, and above the `Table` — the list stays visible/scrollable beneath it, same card-in-card spirit as `ListPanel`'s own toolbar/table/pagination stack.
- **Toggled from `ToolbarSimple`'s "Import" trailing-cluster entry** (see `references/components/data/toolbarsimple.md`) — clicking it opens `ImportPanel` in place; it is not a separate route or drawer. Closed via its own top-right bare `✕` (no label, no border — same affordance weight as `Modal`'s close, positioned absolute top-right of the card) or after a successful import.
- Card surface matches `FilterCard`: white bg, `1px solid --color-border-default`, `12px` radius, `20px 24px` padding — no shadow (consistent with the 2026-07-31 shadow-drop across the DS).
- **Fixed anatomy, two equal-width columns side by side, joined by a decorative dashed connector**:
  1. **Step badge + label row** in each column: a 22px solid-brand circle with a white bold step number (`1`, `2`) + a 14px/600 label immediately right of it. **Both badges always render the same "current" (solid brand) treatment** — this is not a `Steps`-style completion tracker (no green/checked "completed" state, no muted "upcoming" state), because step 2 is not gated behind step 1 finishing; both are simultaneously actionable instructions. Don't import `Steps`' 3-state logic here.
  2. **Step 1 body**: a file chip (light `--color-bg-page` pill, file icon tinted `--color-icon-success`, filename, trailing bordered icon-button with a download glyph) — clicking the icon-button triggers the actual template download; the chip itself is not a button. **Stretches to the full width of its `.ip-step` column** (`width: 100%`, not shrink-to-fit) so both step columns present the same visual weight regardless of filename length — don't cap it with a `max-width` shorter than the column.
  3. **Connector**: a plain `1px dashed --color-border-strong` horizontal line between the two step columns, vertically aligned to the body row (not the label row) — purely decorative flow indicator, not a `Steps` progress line (no color-by-completion, see above).
  4. **Step 2 body, two states**: default = a text-link-style trigger (brand-colored, `file_upload`-rotated icon + "Tải file" + a muted "(Dung lượng tối đa {N}MB)" hint) that opens the native file picker; once a file is selected, swaps to a file chip (same visual as step 1's, showing the picked filename) **plus** a `primary` "Nhập dữ liệu" button that confirms the import — a panel with no way to confirm after selecting a file is an incomplete pairing, same principle as `Table`'s `rowSelection` needing visible feedback in the toolbar above it.
- No `Modal`-style footer (no separate Hủy/Xác nhận row) — the only confirming action is step 2's own "Nhập dữ liệu", which only exists once a file is picked; closing via `✕` at any point is the equivalent of "Hủy".
- **Gap handling**: this is a fixed 2-step anatomy, not a generic wizard — a screen needing a 3rd step or a different flow shape doesn't fit this component; ask before stretching it into something it isn't.
